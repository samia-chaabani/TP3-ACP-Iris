
# 🌸 TP3 — ACP sur le Dataset Iris

## 📌 Description
Travaux pratiques sur l'Analyse en Composantes Principales (ACP) 
appliquée sur le célèbre dataset Iris, réalisés à ENICarthage.

## 🎯 Objectifs
- Appliquer l'ACP sur le dataset Iris (150 échantillons, 4 features)
- Réduire la dimensionnalité de 4 → 2 composantes principales
- Visualiser la séparation des 3 espèces de fleurs
- Interpréter la variance expliquée par chaque composante

## 📁 Contenu
- Notebook Jupyter avec l'analyse complète
- Dataset Iris

## 🛠️ Technologies utilisées
- Python
- Pandas
- Scikit-learn (PCA)
- Matplotlib
- Seaborn
